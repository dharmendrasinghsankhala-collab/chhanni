# Chhanni knowledge base

Short, practical craft rules used by the AI Team (crew / plan / script) and by photo & edit scoring.
Each file is plain markdown: one rule per bullet, source link where a rule came from a specific article.

- Rules are additive: weekly research adds new insights, never silently deletes old ones.
- `models_catalog.json` lists recommended free local models per task. It is advisory only —
  the app never switches models automatically; new models appear as suggestions on the Models page.
- Keep each file under ~400 lines.
